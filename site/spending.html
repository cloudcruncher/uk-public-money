Where £1 goes

How spending on public services splits between functions such as health, education and social protection.

Read this first. The split by function comes from PESA Table 10.1, which covers identifiable spending on services in England only (total expenditure on services, TES). It is not UK total managed expenditure (TME), which is larger: see rule R2 on the reconciliation page. The function split (COFOG) ends in 2024-25: PESA 2026 publishes only aggregates for 2025-26, so that year is a gap, not an estimate. Because the split is England-only and GDP is UK-wide, there is no % of GDP view for it.
